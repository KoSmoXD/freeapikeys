# Trajectory AutoPlayer Android

Experimental Geode trajectory preview for Geometry Dash Android 2.2081. Automatic clicks are **not** implemented. Collision prediction is incomplete.

Use the Android Geode build workflow in GitHub Actions to attempt compiling the native code. Compilation has not been verified; inspect workflow logs and only install a successful `.geode` artifact.

Source: `src/main.cpp`. Configuration: `mod.json`, `CMakeLists.txt`.
